## Googleドキュメントでの設定手順

### 1. ドキュメント作成
1. 新しいGoogleドキュメントを作成
2. 上記のテンプレートをコピー＆ペースト
3. Markdown記法を削除し、書式を手動で設定

### 2. フォント・レイアウト設定
- **フォント**: 游明朝 または Noto Sans CJK JP
- **用紙**: A4縦
- **余白**: 上下左右 2.5cm
- **行間**: 1.15

### 3. 具体的な書式設定

#### タイトル「領収書」
- フォントサイズ: 24pt
- 太字
- 中央揃え
- 上余白: 2cm

#### 領収書番号・発行日
- フォントサイズ: 12pt  
- 右揃え
- 太字

#### 宛名
- フォントサイズ: 16pt
- 太字
- 左揃え

#### 金額ボックス
- 枠線: 2pt黒線
- 内側余白: 15pt
- フォントサイズ: 14pt
- 合計金額のみ太字・大きめ

#### 発行者情報
- 上線: 1pt グレー線
- フォントサイズ: 12pt
- 左揃え

### 4. 角印画像の挿入
1. 「挿入」→「画像」→「アップロード」
2. 角印PNG画像をアップロード
3. 画像サイズ: 約 2.5cm × 2.5cm
4. 配置: 発行者情報の右側
5. テキストの折り返し: 「前面」に設定

### 5. プレースホルダー設定確認

以下のプレースホルダーが正確に入力されていることを確認：

```
{{RECEIPT_NO}}        - 領収書番号
{{REISSUE_MARK}}      - 再発行マーク（通常は空）
{{ISSUE_DATE}}        - 発行日
{{BILL_TO}}           - 宛名
{{DESCRIPTION}}       - 但し書き
{{AMOUNT_TAXIN}}      - 税込金額
{{AMOUNT_TAXOUT}}     - 税抜金額  
{{TAX}}              - 消費税額
{{PAY_METHOD}}        - 支払方法
{{PAY_DATE}}          - 支払日
{{COMPANY}}           - 会社名
{{ADDRESS}}           - 住所
{{TEL}}              - 電話番号
{{EMAIL}}            - メールアドレス
{{INVOICE_NO}}        - インボイス番号
```

### 7. 最終チェック項目

- [ ] すべてのプレースホルダーが {{}} で囲まれている
- [ ] フォント・サイズが統一されている  
- [ ] A4用紙に収まるレイアウト
- [ ] 角印画像が適切な位置に配置
- [ ] 印刷プレビューで確認済み
- [ ] ドキュメントIDをconfig設定に追加済み

### 8. トラブルシューティング

**PDFで文字化けする場合:**
- フォントを「游明朝」に変更
- 特殊文字を避ける

**レイアウトが崩れる場合:**
- 余白設定を確認
- 表やテキストボックスの使用を避ける
- シンプルな改行・スペースでレイアウト調整

**角印が表示されない場合:**
- 画像形式をPNG推奨
- 画像サイズを適切に調整（大きすぎると表示されない）
- 挿入後に「前面」配置を再確認

このテンプレートをGoogleドキュメントに設定後、Apps ScriptでプレースホルダーがPDF出力時に正しく置換されます。
